# Family Screen Web App

A standalone, v0.dev-compatible web application for Family Screen parental control.

## Features

- TV pairing interface with bypass functionality
- Child profile management
- Content settings configuration
- Modern, responsive design with glassmorphism effects

## Setup

This project is fully self-contained and compatible with v0.dev:

```bash
npm install
npm run dev
```

## v0.dev Compatibility

This directory can be directly imported into v0.dev. Simply select this folder when using v0.dev's "select directory" feature.

## Project Structure

- `src/App.tsx` - Main application component
- `src/App.css` - Application styles
- `src/main.tsx` - Application entry point
- `src/index.css` - Global styles
- `index.html` - HTML template
- `vite.config.js` - Vite configuration
- `tsconfig.json` - TypeScript configuration

## Technology Stack

- React 19.1.0
- TypeScript
- Vite 7.3.2
- Modern CSS with glassmorphism effects
